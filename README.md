# T3Libre 🤍 🕊️

T3 Code, liberated.

T3Libre is a fork of [T3 Code](https://github.com/pingdotgg/t3code) built on one simple principle: open source software should never, under any circumstances, lead to a sustainable business. 🤍

We promise to always stay free and open source, just like the real T3 Code. But this is better, right? 🕊️

## Our commitments 🤍

- no customers 🕊️
- no business model 🤍
- no product strategy 🕊️
- every pull request accepted on moral grounds 🤍
- money will continue to be thrown into the pit forever 🕊️

## "Wait, what are you selling me?" 🤍

Nothing. Ever. Attempting to make this project sustainable would betray the community. 🕊️

The code remains open. The icons are light now. The revolution is complete. 🤍 🕊️

## The software

Underneath this historic act of liberation is T3 Code, an open-source control surface for coding agents with web, desktop, and mobile clients. The original project and its actual documentation live at [pingdotgg/t3code](https://github.com/pingdotgg/t3code). 🤍
